# БИТВА ШКОЛ — Russia R4

Продакшен-ориентированная версия рейтинга учебных заведений России на FastAPI + PostgreSQL/SQLite. В архиве нет фотографий школ: все карточки используют placeholder до тех пор, пока администратор не загрузит фото вручную.

## Что внутри

- Общероссийский каталог из исходного CSV и 75 legacy-записей Калининграда.
- Реальные клики считаются только на сервере.
- Базовый лимит: 800 кликов/минуту.
- Подтверждённый подписчик Telegram: множитель ×3, то есть 2400/минуту и 2400 за одну отправку.
- Клиент накапливает клики и отправляет их пачкой примерно каждые 10 секунд.
- Дополнительные ограничения по IP-сети и связке IP-подсеть + User-Agent.
- CAPTCHA через Cloudflare Turnstile с серверной проверкой; режим Invisible поддерживается без видимой CAPTCHA.
- Регистрация аккаунта через Telegram-бота и одноразовый код.
- Проверка подписки на `@AntonLjungberg` через Bot API.
- Админка: добавление школ и фотографий, блокировка identity, журнал abuse, глобальное сообщение на 10 секунд, общий ивент с музыкой и эффектами ±кликов.
- Быстрый поиск городов с алфавитной навигацией.
- Настройки «О проекте», слов автора и доната из админки.
- Автообновление админки и анимированное обновление чисел рейтинга/статистики.
- Рейтинг школ / городов России.
- Статистика «Всего посетителей», «Сейчас на сайте», «Всего кликов», «Школ играет» и график кликов/с за последние 10 секунд.

## Секреты

Реальный токен Telegram-бота и пароль администратора не должны храниться в Git. Задавайте их через переменные окружения на Wasmer/Timeweb. Токен, который был опубликован в чате, перед production лучше заменить через BotFather.

## Быстрый локальный запуск

Windows: `run_windows.bat` → открыть `http://127.0.0.1:8000`.

Для телефона в той же Wi-Fi: `run_windows_lan.bat` и открыть IPv4 компьютера на порту 8000.

Для локального теста бот можно отключить: `BOT_POLLING_ENABLED=false`. Для проверки бот-функции установите реальный `TELEGRAM_BOT_TOKEN` в `.env` и оставьте polling включённым. Не коммитьте `.env`.
